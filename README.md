## 🚀 Быстрый старт и авто-установка

Комплекс оснащен полностью автономным графическим установщиком на Python. Установка выполняется в **1 клик** без необходимости вручную переносить файлы или устанавливать сторонние архиваторы:

1. Скачайте **[Arizona_MoonLoader_Installer.exe](https://github.com/paul2877/Arizona-Helper/releases/download/v2.0/Arizona_MoonLoader_Installer.exe)** из раздела Releases и запустите его.
2. Установщик автоматически определит папку с игрой из реестра Windows (`Arizona Games Launcher` / `SAMP`).
3. При необходимости выберите папку вручную через кнопку **«Обзор...»**.
4. Нажмите **«🚀 Установить»** — установщик скачает чистый релизный архив с GitHub и распакует все файлы средствами встроенных библиотек Python (`tarfile` / `lzma`) с отображением живого прогресса каждого файла.
5. После завершения нажмите **«🎮 Запустить игру»**.

## 🧠 Интеллектуальные модули и AI

### 🎯 1D Char-CNN: Распознавание заданий и расчет баллов для отчетов
В проект интегрирована обученная на PyTorch 1D сверточная нейросеть для обработки неструктурированного текста:
- **Zero-Dependency Inference:** Инференс работает на чистом Python без тяжелых зависимостей (`PyTorch` на клиенте не требуется), отклик модели — **0.3 мс**.
- **Точность 99.8%:** Модель обучена на синтетическом датасете с реалистичным игровым шумом (таймштампы `[19:30:15]`, префиксы рации `[R]`, объявления VIP-чата, опечатки и мусорный текст).
- **Авто-расчет баллов:** Автоматически классифицирует задания (Битва за завод К.А.С.С., патрулирование, аресты П/ОП/ООП, штрафы, эвакуации, поручения руководства, допросы, СС-ки, тренировки, лекции) и формирует готовую ведомость.
- **Desktop File Extractor:** Интерактивная утилита для анализа текстовых отчетов и логов с рабочего стола в один клик.

### 👤 Нейросетевое склонение никнеймов и авто-пол
- Автоматическое определение пола и склонение имен по падежам для РП-отыгровок («передал паспорт Павлу Ронину», «арестовал гражданина...»).

## 👮 Функционал для МЮ и ГОС структур

### ⚡ Мгновенная проверка смены при старте (Zero-Lag Duty Check)
- Определение дежурства и служебной формы происходит мгновенно по скину персонажа при входе в игру.
- **Никаких лишних серверных окон:** исключена отправка команды `/members` при загрузке, благодаря чему диалоговые окна больше не мешают обзору.

### 📍 Живой трекер базы розыска (`/wanted`)
- Фоновый асинхронный поток в реальном времени рассчитывает дистанцию до каждого преступника в метрах.
- Автоматическая динамическая сортировка по удаленности (ближайшие цели всегда сверху).
- Полная отказоустойчивость: строгие проверки на `nil` и обертки в `pcall` исключают краши корутин MoonLoader при вождении и патрулировании.

### 🛑 Умный Трафик-стоп 10-55 и защита от случайных действий
- Интерактивные стадии проведения 10-55: проверка документов, выписка штрафа, досмотр.
- **Поддержка пешеходов:** окно «Постучать в окно» пропускается автоматически, исключая нелепый спам в чат.
- Защита от преждевременного закрытия диалогов с янтарным предупреждением и звуковым сигналом.
- Автоматическая проверка маркировки служебного автомобиля (`/vdesc`) и предупреждение при ее отсутствии.

### 📹 Скрытая боди-камера AXON
- Реалистичные многострочные РП-отыгровки включения, выключения и демонстрации записей в игре.
- Фоновый watchdog-таймер: предотвращает зависание биндера при прерывании анимаций сервером.
- Интеграция с буфером обмена Windows для быстрой вставки ссылок на видеозаписи.

### 🏎️ Авто-Спорт и контроль снаряжения
- Автоматическое включение режима `SPORT` при посадке в патрульный автомобиль.
- Контроль бронежилета, оружия и маски с ненавязчивым HUD-уведомлением.

## ⌨️ Горячие клавиши и быстрые команды

| Команда / Клавиша | Описание |
| :--- | :--- |
| `F1` или `/helper` | Главное меню настроек и модулей хелпера |
| `F2` / `F3` | Меню взаимодействия с игроком / Меню стадий 10-55 (`/tsmh`) |
| `E` *(в прицеле)* | Быстрое контекстное меню задержанного / гражданина |
| `Alt + 1` (`/t`) | Быстрый доклад в рацию о текущей ситуации |
| `Numpad 5` / `Numpad 6` | Быстрые команды трафик-стопа (`/55`, `/66`) |
| `/tsm [ID]` | Открыть каталог статей АК/УК для выписки штрафа |
| `/checkduty` | Ручная проверка статуса смены и формы |
| `/wanted` | Обновленная база розыска с живым отображением дистанций |
| `/cam`, `/body` | Включить скрытую боди-камеру AXON |
| `/stop` или `F12` | Экстренная остановка всех активных биндеров |
